# Bright-Future
A school assignment turned personal practice project.

Scenario
You have recently been appointed as a Junior Python Developer at Bright Future High School. The school administration currently records student marks 
manually, which makes it difficult to organize information and calculate annual averages efficiently. To improve the process, the principal has requested a 
simple menu-driven Python application that will allow teachers to manage student academic records electronically.
